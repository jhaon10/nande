# Cómo correr el proyecto en tu computador

> 🚧 Esta guía se completará cuando exista el primer código (Fase 1).

Objetivo final: que cualquier persona pueda hacer esto en menos de 10 minutos.

```bash
git clone https://github.com/[usuario]/nande.git
cd nande
docker compose up
```

## Requisitos previstos

- Git
- Docker
- Node.js (versión LTS) y pnpm

## Alternativa sin instalar nada

Se prevé un entorno en GitHub Codespaces para colaborar desde el navegador.
