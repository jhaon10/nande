# Código de conducta

Este proyecto adopta el [Contributor Covenant v2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Reglas específicas del proyecto

- **Cero propaganda partidista** en el repositorio y en los canales oficiales.
  Se puede hablar de políticas públicas y datos; no se hace campaña.
- Se discuten ideas, no personas.
- En un proyecto latinoamericano se discute de política: es normal. No es excusa
  para faltar el respeto.
- Se asume buena fe.
- Se respeta cada país, cada variante del español y cada idioma.
- Las reglas se aplican igual a todas las posturas.

## Reportar un problema

Escribí a [correo del proyecto]. Los reportes son confidenciales.

## Consecuencias

Advertencia → suspensión temporal → expulsión, según la gravedad.
